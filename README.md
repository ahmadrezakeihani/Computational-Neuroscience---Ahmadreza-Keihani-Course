# Computational Neuroscience (Intermediate Level)
### Ahmadreza Keihani, PhD

Welcome to the **Computational Neuroscience Course** repository! This course introduces students and researchers to computational methods for analyzing brain data, understanding neural systems, and developing computational models.

The course combines theoretical foundations with hands-on programming exercises and practical applications in neuroscience.

## Intermediate-Level Course

### Session 1: Orientation and Course Setup

- Welcome and course introduction
- Course structure and expectations
- Introduction to course materials
- Installation and setup of the required software and tools

### Session 2: Python for the Practicing Computational Neuroscientist

- Introduction to programming concepts, terminology, datasets, and data modalities
- Programming mindset, algorithms, and flowcharts
- Introduction to PyCharm, Google Colab, and Jupyter Notebooks
- Variables, operators, and data types
- Hands-on programming exercises

### Session 3: Brain-Signal Analysis in Python

- Introduction to electroencephalography (EEG)
- Event-related potentials (ERPs)
- Practical analysis of brain signals
- Case study: An EEG-based ERP experiment

### Session 4: Exploring Brain Data Beyond the Basics

- Introduction to spectral analysis
- Understanding the intuition behind the power spectrum
- Computing and interpreting the power spectrum of brain signals

### Session 5: Hands-On Practice with Brain Data

- Introduction to Python modules and packages
- Working with NumPy and Pandas
- Brain-data visualization using Matplotlib and Seaborn
- Introduction to graphs and data visualization
- Practical analysis of filtered EEG data

### Session 6: Advanced Applications with Brain Data — Guest Lecture

- Selected topics in computational neuroscience
- Practical examples and current research applications

### Session 7: Toward AI for Science and Neuroscience — Guest Lecture

- Introduction to machine learning and artificial intelligence
- Introduction to scikit-learn and TensorFlow
- Machine learning and deep learning in cognitive and computational neuroscience
- Applications of AI to brain-data analysis

### Session 8: Interrogating Your Data

- Introduction to basic statistical tests
- Selecting appropriate statistical methods
- Running and interpreting statistical analyses
- Validation measures: true positives, true negatives, false positives, and false negatives
- Surrogate data analysis
- Permutation testing

### Session 9: Data Collection, Task Design, and Experimental Design

- Introduction to experimental and study design
- Task-based versus resting-state data
- Data specifications and considerations in neuroscience
- Introduction to PsychoPy and Psychtoolbox
- Practical considerations for neuroscience data collection

### Session 10: Models and Modeling

- Introduction to mathematical and statistical models
- General linear models (GLMs)
- Model fitting and evaluation
- Comparing alternative models
- Critically evaluating model assumptions and performance

### Session 11: Neural Time-Series Analysis and Beyond — Guest Lecture

- Introduction to neural time-series analysis
- Temporal dynamics of brain signals
- Cross-frequency coupling of neural signals
- Introduction to natural language processing (NLP)
- Discussion of the relevance and interpretation of these methods
- Course wrap-up and introduction to advanced topics

## Advanced Computational Neuroscience Course

The advanced course was designed as a follow-up to the intermediate course, focusing on practical neuroimaging and brain-signal analysis.

- **Planned Schedule:** Winter 2023–May 2024
- **Day:** Sunday mornings (Pittsburgh time)
- **Duration:** 10 sessions

### Sessions 1–4: EEG Signal Analysis

- Task-based EEG analysis
- Resting-state EEG analysis
- Signal preprocessing and feature extraction
- Practical EEG analysis workflows

### Sessions 5–8: Functional MRI Analysis

- Introduction to functional magnetic resonance imaging (fMRI)
- Task-based fMRI analysis
- Resting-state fMRI analysis
- Practical neuroimaging data-processing and analysis workflows

### Session 9: Developing Your Own Computational Neuroscience Library

- Designing reusable computational workflows
- Organizing code into functions and modules
- Developing a MATLAB toolbox or Python package
- Documentation, reproducibility, and code reuse
- Applying these concepts to a computational neuroscience project

### Session 10: Course Wrap-Up and Conclusion

- Review of key concepts and methods
- Discussion of practical challenges in computational neuroscience
- Integration of programming, data analysis, and computational modeling
- Recommendations for further study and research

## Learning Objectives

By the end of the course, participants should be able to:

1. Understand fundamental concepts and computational approaches in neuroscience.
2. Write Python code for scientific computing and neuroscience applications.
3. Analyze and visualize EEG and other neural time-series data.
4. Apply statistical methods and validation techniques to neuroscience datasets.
5. Understand the foundations of machine learning and its applications to brain data.
6. Develop computational models and evaluate their performance.
7. Understand experimental design and neuroscience data collection.
8. Build reproducible analysis workflows and reusable software packages.
9. Develop a foundation for advanced research in computational neuroscience and neuroimaging.
